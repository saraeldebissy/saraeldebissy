# Product

## Register

brand

## Users

Recruiters, hiring managers, fellow designers/engineers, and collaborators who land on github.com/saraeldebissy via a repo link, a pinned project, or a direct profile search. They're scanning fast, often on a laptop in normal office light, deciding in seconds whether this person is worth a deeper look.

## Product Purpose

A personal GitHub profile README that functions as a living portfolio cover page. It exists to make Sara's identity as a "forward-deployed designer & design engineer" (someone who designs, builds, and ships, not just hands off files) immediately legible, memorable, and distinct from every other designer's profile. Success is a visitor clicking through to a real project within the first 10 seconds.

## Brand Personality

Forward-deployed hacker-builder. Fast, technical, unafraid of a terminal. Confident without corporate polish. Three words: precise, technical, alive (not static).

## Anti-references

Explicitly reject: generic light-mode SaaS dashboard UI (white rounded cards, pastel badges, soft drop shadows, Notion-style panels) — this reads as derivative AI-generated template work, not as a personal, technical identity. Also reject: gradient-text hero metrics, glassmorphism, identical card grids.

Equally reject the failure mode that replaced it: dark-mode markdown. Uniform full-width bands, every section the same height and rhythm, hierarchy carried only by font size. Dark is not the same as designed. The page needs density, asymmetry, and machine furniture (indices, readouts, status chips, rulers) or it is just a document with the lights off.

## Design Principles

- Show, don't tell: the interface itself should prove "design engineer," not just claim it in text.
- Terminal-native: the whole page behaves like a retro CRT terminal session, not a dashboard wearing dark mode.
- Earned texture: scanlines, glow, and vignette exist because they reinforce the CRT metaphor, not as decoration.
- Content stays real: every project, link, and quote reflects what's actually true and live, never a placeholder. Numbers that look live must be live — a hardcoded streak is a claim the page cannot keep.
- One brand thread: the violet/coral accent system carries through every section so the page reads as one considered system, not stitched-together blocks.

## Accessibility & Inclusion

Standard WCAG AA contrast for body text against the dark background. Scanline/glow effects are decorative overlays only (implemented as static baked-in image texture, not live CSS animation), so they don't trigger motion-sensitivity concerns and remain readable in GitHub's rendering.
